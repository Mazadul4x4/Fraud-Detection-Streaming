# Data

Raw and processed data are **not committed** to Git (file size limits and good practice).

## Source
[Credit Card Transactions Fraud Detection Dataset](https://www.kaggle.com/datasets/kartik2112/fraud-detection) (Kaggle, by kartik2112) - simulated card transactions.

| File | Description |
|---|---|
| `raw/fraudTrain.csv` | Training period transactions |
| `raw/fraudTest.csv` | Later period transactions (used as a held-out stream) |

## Download
1. Create a Kaggle API token and place it at `~/.kaggle/kaggle.json`
2. Run:

```bash
kaggle datasets download -d kartik2112/fraud-detection -p data/raw --unzip
```

## Folders
- `raw/` - original files, never modified
- `processed/` - cleaned data and engineered features (generated by code)
